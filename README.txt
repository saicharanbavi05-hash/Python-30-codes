Python-30-codes

This folder contains separate Python examples transcribed from the screenshots provided.
Files Py1.py through Py29.py are individual class, object, constructor, inheritance,
method-overriding, and basic operator examples. Bank_Account.py is based on the
WhatsApp bank-account exercise screenshot.

Notes:
- Py3 duplicates Py1 and Py4 duplicates Py2 in the supplied screenshots.
- Py12 duplicates Py11.
- Py8's screenshot contained a repeated pasted copy; the duplicate was removed.
- A few obvious OCR/typing issues were normalized so the scripts are valid Python
  (for example, lowercase letter l in rectangle parameters and the Dog sound method).
- The bank-account exercise screenshot was partly unclear, so that example is a
  reasonable reconstruction of the visible instructions, not a guaranteed exact copy.
